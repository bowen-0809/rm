# 第二周周结

## 一、本周主要工作

**1. 资料学习**

- 考核要求：用 GM6020 **分别**跟随正弦速度/位置曲线（曲线自定义）+ **看门狗保护** + 代码上传 GitHub（public）。
- 学习拨码/指示灯、电压控制帧、反馈帧、滤波器、Ozone 调试、速度环、角度环、PID 、两个限幅、上电锁位、排错表。

- 通读工程：`Tasks/Task.cpp`（控制主体）、`Gm6020.*`（协议封装）、`Core/*`（CubeMX 外设），确认 TIM6=1kHz、CAN1=1Mbps、IWDG 超时≈0.8s。

**2. 控制方案设计（串级 PID）**

- 结构：**位置环(外) → 速度环(内) → 电流指令**；采用培训版 PID 规范——**微分对测量值**、**积分限幅**。
- 三种模式（全局 `g_mode` 可切、Ozone 在线可改）：`3`=位置正弦、`2`=速度正弦、`1`=开环（调试用）。
- 位置模式实现"**上电锁位**（θ0 只锁一次）"与"**速度前馈**"以减小相位滞后。

**3. 代码实现**

- PID（`Pid_Step`）、串级双环、三种模式、上电未收帧保护、`g_trace` 轨迹记录。
- **看门狗**：1ms 回调里无条件喂狗 + `__HAL_DBGMCU_FREEZE_IWDG()`（调试暂停不误复位）。
- **电流模式**：控制帧 `0x1FF→0x1FE`，数值范围 `±25000→±16384(±3A)`，限幅取额定 1.62A。
- 曲线参数按手册选定：速度正弦 150rpm@0.5Hz、位置正弦 ±120°@0.5Hz。

**4. 实机调试（速度环）**

- 自检：`g_tick`≈1000/s、`rx_count` 持续增长、`tx_drop` 不涨。
- 开环（`g_mode=1`）验证转向与电流方向。
- 速度环调参：P→I→D 逐步整定，最终 **kp=20、ki=2.6、kd=0.065**。

**5. 实机调试（位置环）**
- 位置环调参：P→I→D 逐步敲定，最终 **kp=3.3、ki=0、kd=0**
