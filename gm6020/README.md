# GM6020 正弦速度/位置跟随（串级 PID + IWDG 看门狗）

STM32F407（RoboMaster 开发板 C 型）通过 CAN 以**电流模式（转矩电流）**驱动 GM6020 直流无刷电机，
在 **1 kHz 定时器中断**里运行**串级 PID**（位置环 → 速度环），让电机跟随**自定义正弦曲线**，
并使用**独立看门狗（IWDG）**保护。

---

## 1. 硬件与通信

| 项 | 值 |
|---|---|
| 主控 | STM32F407IGHx（RM 开发板 C 型），168 MHz |
| 电机 | GM6020（内置驱动器 + FOC），拨码 **ID = 1** |
| 总线 | CAN1，**1 Mbps**，PD0=CAN1_RX / PD1=CAN1_TX |
| 反馈帧 | `0x204 + ID` → ID=1 时为 **0x205**，1 kHz |
| 控制帧 | **0x1FE**（ID 1~4）/ **0x2FE**（ID 5~7）标准帧，8 字节（**电流控制**） |
| 电流给定 | **−16384 ~ +16384**（对应转矩电流 ±3 A） |
| 角度反馈 | 机械角度 0 ~ 8191（8192 = 一圈） |
| 转速单位 | rpm |
| 控制周期 | **1 ms（1 kHz）**，TIM6 中断 |
| 看门狗 | IWDG，预分频 64、重装 400 → 超时 **约 0.8 s**，1 ms 喂一次 |

> ⚠️ **前置条件**：电机必须处于**电流模式**（用 RoboMaster Assistant 调参软件打开"电流环开关"，
> 需固件 ≥1.0.11.2、Assistant ≥2.7）。此时**指示灯橙灯常亮**是正常现象。
> 若电机在电压模式（出厂默认），控制帧标识符要用 `0x1FF`、数值范围 ±25000。

> 接线：CANH（红）/ CANL（黑）；总线**两端各 120 Ω**（电机拨码第 4 位 ON）。
> 拨码 ID=1：第 1 位 ON、第 2/3 位 OFF、第 4 位 ON。

```

  Gm6020.h/.cpp   GM6020 CAN 协议封装（class Gm6020，负责按 ID 填帧字节）

CMakeLists.txt    构建脚本（自动收集 Core / Drivers / Tasks）
```

> 注：`Tasks/Task.cpp` 直接发送 **电流控制帧 0x1FE**；`Gm6020` 类只负责把 int16 填到对应 ID 的
> 两个字节（电压/电流帧的字节布局相同），因此无需修改该类。

## 3. 控制原理

- **GM6020 内部闭环**（电流环 + 换相）；主控发给电机的是"**转矩电流指令**"，
  外部自建位置/速度环。
- **PID（培训版）**：`u = Kp·e + Ki·∫e dt − Kd·(d测量值/dt)`
  - **微分对"测量值"做**（不对目标做），避免目标跳变产生尖峰；
  - **积分限幅 `i_max`**，防止积分饱和。
- **串级**：
  - 外环 **位置环**：角度误差(°) → 目标转速(rpm)
  - 内环 **速度环**：转速误差(rpm) → 电流指令
  - 先调内环，再套外环。
- **看门狗**：1 ms 里 `HAL_IWDG_Refresh`；`__HAL_DBGMCU_FREEZE_IWDG()` 让内核暂停时冻结看门狗，
  以便 Ozone 调试时打断点不误复位。

### 三种模式（`g_mode`，Ozone 里可直接改）

| `g_mode` | 模式 | 说明 |
|---|---|---|
| 0 | 位置正弦 | `θref = θ0 + A_p·sin(2π f_p t)` → 位置环(+速度前馈) → 速度环 → 电流 |
| 1 | 速度正弦（默认） | `ωref = A_v·sin(2π f_v t)` → 速度环 → 电流 |
| 2 | 开环 | 固定电流 `openloop_curr`，忽略反馈（调试/验证转向用） |

### 可调参数（均可在 Ozone 里在线修改）

| 变量 | 默认 | 含义 |
|---|---|---|
| `g_mode` | 1 | 模式选择 |
| `vel_amp_rpm` / `vel_freq_hz` | 60 / 0.5 | 速度正弦幅值(rpm) / 频率(Hz)（隐含摆幅 ±115°） |
| `pos_amp_deg` / `pos_freq_hz` | 90 / 0.5 | 位置正弦幅值(°) / 频率(Hz) |
| `openloop_curr` | 1000 | 开环模式固定电流指令 (counts, ±16384↔±3A) |
| `speed_pid` | kp=25, ki=10, kd=0, out=±8800(≈1.6A≈额定), i_max=200 | 速度环 |
| `angle_pid` | kp=1,  ki=0, kd=0, out=±80rpm, i_max=20 | 位置环 |

> 注：以上 PID / 曲线参数为**未实机验证的初始基线**（换电机后从这组重新调）。

> 参数依据《RM GM6020 使用说明》(24V)：空载最高 320 rpm、额定转矩下调速 0~132 rpm、
> 转矩常数 741 mN·m/A、额定电流 1.62 A、额定扭矩 1.2 N·m、机械时间常数 3 ms、定位精度 0.05°。
> - 速度环 **Kp=25 / Ki=10 / Kd=0**（实测：Kp 再高电机会抖；整数 rpm 微分放大噪声，不用 D）；
> - 速度环 **out=±8800** ≈ 额定电流 1.62 A（限流保护，不超额定）；
> - 角度环 **out=±80 rpm** ≤ 额定转矩调速上限 132 rpm；
> - **不使用任何滤波**：PID 直接用原始转速反馈（`g_motor.rpm`）。
> 取 0.5 Hz 使 1 个周期 = 2 s，正好填满 `g_trace` 的 200 点（每 10 ms 一点）窗口。

## 5. 测试步骤（SOP）

> 原则：**每一步只做一件事、只看一对线、一次只改一个参数。**

### 第 0 步 · 准备
接线、拨码 ID=1、两端 120 Ω；确认电机处于**电流模式**（橙灯常亮）；编译烧录；Ozone 里加好 Watch：
```
g_tick   rx_count   tx_drop   g_mode
g_motor            (展开)
speed_pid  angle_pid
```
Timeline/Data 里加：`g_motor.target_rpm`、`g_motor.rpm`。

### 第 1 步 · 上电自检（先别管电机转不转）

| 观测对象 | 合格标准 | 不达标 → 查 |
|---|---|---|
| `g_tick` | 每秒 ≈ 1000 | TIM6 / 时钟 |
| `rx_count` | 持续增长 | CAN 接线 / 波特率 / 滤波器 |
| `tx_drop` | 基本不动 | 总线异常 / 邮箱满 |

### 第 2 步 · 开环确认转向（`g_mode = 1`）
1. Ozone 里把 `g_mode` 改为 **2**；
2. 改 `openloop_curr`（默认 **1000**，≈0.18 A；不动就加大到 2000~3000）；
3. **观测**：`g_motor.current` 是否 = 设定值、电机是否转、转向对不对；
4. 方向反了 → 在发送前对电流取负；
5. 测完把 `g_mode` 改回 1（或 0）。

### 第 3 步 · 速度环调试（`g_mode = 2`）
**观测对**：`g_motor.target_rpm`（给定，绿）⟷ `g_motor.rpm`（反馈，红）；辅助 `g_motor.current`。

| 顺序 | 改谁 | 期望 | 不达标 → 调 |
|---|---|---|---|
| ① P | `speed_pid.kp`（起 30） | 红线跟绿线动起来 | 不动→加倍；来回甩→减半 |
| ② I | `speed_pid.ki`（从 10 起） | 幅值变大、滞后变小 | 幅值偏小/停在下面→加大 |
| ③ D | `speed_pid.kd`（从 0.05 起，可保持 0） | 过冲变小 | 转速噪声会被放大，宁小勿大 |

**合格**：红线与绿线形状一致、幅值接近、相位滞后小。

### 第 4 步 · 位置环调试（`g_mode = 3`）
前提：速度环已调好，**不要再动 `speed_pid`**。
**观测对**：`g_motor.target`（给定, °）⟷ `g_motor.angle_deg`（反馈, °）；另看内环 `g_motor.target_rpm` ⟷ `g_motor.rpm`。

| 顺序 | 改谁 | 期望 | 不达标 → 调 |
|---|---|---|---|
| ① P | `angle_pid.kp`（起 1） | 红线跟上绿线 | 跟得慢→加大；两端过冲/来回摆→减小 |
| ② I | `angle_pid.ki`（很小起） | 稳态偏差消失 | 有稳态差→加大 |
| ③ D | `angle_pid.kd` | —— | **保持 0** |

**合格**：角度反馈贴着给定摆动；上电先从**当前位置**开始（`hold_inited` = 1）。

### 第 5 步 · 看门狗验证

| 观测对象 | 期望 |
|---|---|
| 正常运行 `g_tick` | 一直涨、不复位 |
| **脱机**跑 + 临时注释 `HAL_IWDG_Refresh` | 约 0.8 s 复位（验证保护生效），验完恢复 |

> 必须**脱机**测（带调试器时看门狗被 DBGMCU 冻结，看不到复位）。

### 第 6 步 · 记录 + 固化
1. 两种模式各截一张 Data 图（给定 vs 反馈）；
2. 把调好的 `kp/ki/kd` **写回 `Task.cpp` 的初值**并重新编译（Ozone 改的是 RAM，掉电会丢）。

### 一页速查

| 阶段 | 模式 | 观测的两个对象 | 调谁 |
|---|---|---|---|
| 自检 | — | `g_tick` / `rx_count` | — |
| 开环 | 2 | `g_motor.current` / 电机转向 | `openloop_curr` |
| 速度环 | 1 | `g_motor.target_rpm` ⟷ `g_motor.rpm` | `speed_pid.kp/ki/kd` |
| 位置环 | 0 | `g_motor.target` ⟷ `g_motor.angle_deg` | `angle_pid.kp/ki/kd` |
| 看门狗 | — | `g_tick`（是否复位） | — |

## 6. 排错速查

| 现象 | 原因 |
|---|---|
| `g_tick` 不涨 | TIM6 时钟 / 中断没进回调 |
| 绿灯闪 1 次但 `rx_count = 0` | CANH/CANL 反、未共地、无 120 Ω、非 1 Mbps、滤波器 |
| 橙灯常亮 | **电流模式**（本项目即用电流模式，属正常）；若要改用电压模式需关电流环 |
| 一给输出就狂转 | 电流符号反，或 Kp 大了一个数量级 |
| `tx_drop` 一直涨 | 邮箱满 / 自动离线恢复 |
| 暂停就复位 | IWDG（本工程已用 DBGMCU 冻结，除非脱机运行）|
| 用电压帧(0x1FF)给电流模式电机 | 橙灯常亮、电机不响应 → 改用 0x1FE |
